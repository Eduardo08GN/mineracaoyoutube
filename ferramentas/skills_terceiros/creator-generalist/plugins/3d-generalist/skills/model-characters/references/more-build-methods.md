# More Build Methods: stylized head and shaping-trio methods

Other ways to build the same kind of character, from two more methods. Use them when the reference is not anime
(Wind Waker, Mega Man Legends, cartoon, mascot, game NPC), or when a part of the main method does not fit. The main
method in `modeling-and-topology.md` and `head-and-face.md` stays the default for anime turnarounds.

## Reading Map

- Stylized head method: stylized head, body from cylinders, hair shell from head faces, one 1K texture, hand painting, 2D face atlas switched by a bone, blinking eye plane
- Head-ruler method: head ruler in heads, shaping trio, body build order, clothes as loop-cut shells, hair and vest by knife, accessories, hats, finishing

Blender 5.x notes: LoopTools is an extension (Edit > Preferences > Get Extensions). Texture Paint palette sample is
`Shift+X` in 4.x and later. Recheck any other name in the installed build.

## Stylized head and body

- **[low-poly] Modeling a stylized head (Wind Waker / Mega Man Legends style)**: simple head with facial features painted, not modeled.
  - Steps: Add cube, add Subdivision Surface, apply it for a sphere; delete half; Mirror modifier with Clipping checked (merges center points). Shape with proportional editing (`O`, 4.x also shown in header) and toggle X-ray with `Alt+Z` to see the reference. Pull down front points and cut a simple nose with the Knife tool. Anime proportions: tall forehead, lower face pushed out. Reference: drawn concept dragged in as an empty image.
  - Use when / pitfalls: for Blender older than 4.0 the modifier menu looks different but the modifiers are the same. Keep low-poly by painting eyes/mouth in the texture.

- **[low-poly] Torso, arms, legs and shoes from cylinders**: whole body from a few primitives.
  - Steps: torso = 8-sided cylinder, cut in half, Mirror, add loop cuts, flatten and pull points. Arm: select top two faces, Inset (`I`), right-click > Loop Tools > Circle (enable the free Loop Tools add-on in Preferences), pull out, delete middle faces, extrude for sleeve. Hand: extrude, scale on Y, flatten, round; one thumb extrusion; fingers painted in the texture. Add loop cuts at elbow, knee and fingers for deformation. Legs: 6-sided cylinder, rotate so the flat face is front, Mirror, delete top and bottom, extrude with a V shape, Clipping on, `F` fills two edges, scale a selection by 0 on one axis (`S` `Z` `0`) to flatten. Shoes: extrude front faces, loop cuts, lip cut for sole, extrude top faces for tongue. Join all with `Ctrl+J`, merge vertices with `M`; `Shift+R` repeats the last action. Switch to smooth shading to spot problems; rename objects.
  - Use when / pitfalls: "with less geometry you have to be deliberate"; put extra loops where joints bend.

- **[low-poly] Hair shell and thickness**: hair from duplicated head faces.
  - Steps: select head faces, `Shift+D` then `P` to separate, `Alt+S` (Shrink/Fatten) to inflate along normals so it stays aligned, carve back and bangs by extruding, add cuts. Add Solidify for thickness (with "Only Rim" if you want to avoid filled inner faces). Bun = subdivided cube. Ears = flattened cylinder. Delete hidden head faces under the hair to cut polys.
  - Use when / pitfalls: apply Solidify only after deleting any stray middle faces and keeping centre points merged; some visible faces may need filling manually.

- **[low-poly] UV unwrap a whole character to one 1K texture**: single texture with checks.
  - Steps: Image Editor/N panel > Image > New > UV Grid or Color Grid to see stretching, switch back to blank before painting (grid would bake into the texture). Material: image texture into Emission for unlit style. Apply the material to many objects: select all, make the one with the material last/active, `Ctrl+L` > Link Materials. Mark seams in hidden places or sharp corners, separate parts (shoes vs socks vs legs), `Shift+R` repeats seam marking. Cut areas with distinct colour (shadow under arm) into their own islands. Unwrap with a larger margin to avoid overlap. Organize islands into groups (clothes, skin, hair). Face: Project from View (front orthographic) for a flat UV.
  - Use when / pitfalls: little stretching is fine for flat painting; crunchiness from one shared texture is part of the look.

- **[texturing] Hand-painting a low-poly character in Texture Paint**: flat unlit painting with shadows painted in.
  - Steps: Texture Paint mode; create a palette and sample reference colours (`Shift+X` in 4.x; was `S`); block colours with the Fill tool using Paint Mask (square button: paints only on faces selected in edit mode); raise Bleed (in options) to hide seams; `L` in face-select mode selects a UV island. Save the image often (`Alt+S` while hovering). Brush: Falloff = rounded shape (default too soft), pen pressure off for flat colour, Stabilize stroke for line details. Overlays > Wireframe at low opacity shows where you paint; Solid view with flat lighting is more responsive than Material Preview. Turn off Occlude and Backface Culling to paint through the model (mirror a line on both sides), turn back on after. Toggle the mirror modifier visibility icon for in-between areas. Paint shadow shapes (under hair, arm undersides) because geometry is minimal. Use a second viewport for a far view of the model. Face is best painted in an external program (Photoshop) but x-ray front view works.
  - Use when / pitfalls: save before closing, Blender will not auto-save the image.

- **[texturing] 2D face texture atlas with a bone-driven switch (Animal Crossing style)**: change expressions by sliding UVs across a texture, driven by a control bone.
  - Steps: (1) Separate face into its own material slot: duplicate the character material, name it "face", Edit Mode, select face area, Assign. Apply the Mirror modifier on the head first so the face can be asymmetric. (2) New 1K image for the face material. (3) Unwrap the face with Project from View; fit the UVs into the top-left cell of a grid (the face UV centred, X coordinate of the island 0.25). Use UV Grid/Color Grid image during setup, then blank again; split the texture in 4 rows/columns so each face is 0.25 apart. Export UV layout (UV menu > Export UV Layout) to paint over. (4) Paint faces in Clip Studio Paint / Krita / Photoshop with a grid set to 256 px (a quarter of 1K); copy a face and move it down one cell snapped to the grid. Reload in Blender with `Alt+R` over the image; hide the UV layout layer first. (5) Shader: add Mapping node (`Ctrl+T` with Node Wrangler on the image texture), use Combine XYZ nodes for each face offset (0, 0.25, 0.5, 0.75 on Y; adjust X to 0.5 for right-side columns), chain Mix nodes (Vector) A = previous, B = next face; drive them from one Value node with Math nodes set to Greater Than with thresholds 1, 2, 3. (6) Make a bone: `Shift+A` in Armature edit mode, Roll 0, Z up, name "face_select", own bone collection. Right-click the Value > Add Driver: object = armature, bone = face_select, Local Space Z Location, expression `var * 10`. Add a Limit Location constraint (X,Y in Local Space) so the bone only slides up/down; optionally cap Z. (7) Separate eyes and mouth: duplicate material slots "eyes" and "mouth", assign each area, duplicate the select bone to `eye_select`/`mouth_select` and set each driver to its bone.
  - Use when / pitfalls: set interpolation of keyed values to Constant when keyed directly so faces do not blend; with a bone you animate the face in the normal pose workflow.
  - 2D too: same as swapping drawn mouth shapes/eyes on a 2D character frame by frame (mouth chart for lip sync).

- **[texturing] Blinking eyes on a floating eye mesh**: eye plane in front of the face with its own texture.
  - Steps: model eyes as a separate mesh slightly in front of the face with its own texture (open/closed drawn side by side), Mapping node location offsets the UV between open and closed, keyframe the Mapping location and set the keys' interpolation to Constant.
  - Use when / pitfalls: gives instant blinks; interpolation must be Constant or the eyes slide.
  - 2D too: a blink is held closed for 1-2 frames, quick open, like a 2D smear-less blink.

## Head ruler and shaping trio

- **[low-poly] Start a head from a subdivided cube, then size the body in "heads"**: a rounded head base and a proportion ruler.
  - Steps: `A` `X` delete all; `Shift A` > Mesh > Cube; `S` `0.1` Enter (real-world head size, default cube is taller than a person); `Ctrl A` > Scale to apply. Modifiers > Add Modifier > Generate > Subdivision Surface, Levels Viewport 1 and Render 1, then dropdown > Apply so the rounded cube becomes real geometry. `Numpad 1`, hold `Z` > Wireframe, `A` `A`, `B` box over half, `X` > Vertices, add Mirror (axis X) with Clipping on. Shape: `G` `X` pull a side vertex in for a flatter temple; face select `3` two bottom faces `G` `Z` down; `Ctrl R` loop cut (left click, then right click to keep centred); edge select `2` pull a jaw edge down. Ruler: Object mode `Shift D` `Z` to copy the head down, then `Shift R` repeats the last duplicate-and-move; make 8 heads for an adult (he ended at about 7.5 because 8 made the legs too long). Delete the copies or `M` > New Collection ("hide"), untick the checkbox in the Outliner to keep them in the file but hidden.
  - Use when / pitfalls: apply the Subdivision modifier before deleting half or the edit mesh stays a low-poly cube. Apply scale before modifiers.

- **[low-poly] Edge slide, Alt-S normal scale, Ctrl B bevel: the shaping trio**: cheap ways to round and fatten a blocky body.
  - Steps: `G` `G` (double tap) = edge slide of the selection along its edges, used constantly to even the loops. `Alt S` scales along face normals (works on selected face loops: fatter arm, thicker shirt layer, slimmer neck; hold `Shift` for fine control). Select an edge loop with `Alt` click, `Shift Alt` click adds more loops. `Ctrl B` on an edge loop bevels it (scroll the wheel for more cuts), used to add loops where a calf, waist or hip needs more geometry. `S` `X` `0` flattens selected vertices onto one plane. With `G` held, `Shift` slows movement.
  - Use when / pitfalls: Alt S differs from `S`: it keeps the silhouette thickness uniform instead of scaling to the centre. Turn Proportional Editing off (`O`, or Esc while using it) before scaling a loop, or it drags neighbours.

- **[low-poly] Body build order from the neck down (hands, torso, legs, feet)**: a reusable extrude sequence for a mitten-hand, A-pose character.
  - Steps (new relative to ryanking-1): neck face extrude `E` then `Z` `Z` to move along global Z (second `Z` switches from normals); delete the shoulder face with `X` > Faces (not Vertices, that kills the neck); extrude edge loops sideways for shoulders and `F` to fill a gap. Make the shoulder ring round with LoopTools Circle (N panel > Edit tab > LoopTools; Blender 4.2+ install it from Edit > Preferences > Get Extensions, search "loop"), then extrude out an A-pose arm with `E`, `R`, `G`. Wrist is flattened to an oval with `S` `Z`; palm gets `S` `Y`; fingers are a single mitten extrude; the thumb is a face extruded in top view. Torso: extrude loops down, `S` `Z` flatten, make an S-curve spine in side view (`Numpad 3`) by scaling on Y and moving forward for the belly/chest. Use local view `Numpad /` to hide the head ruler. Pelvis: fill with `F`, extrude leg ring `E`, `S` `Z` `0`, LoopTools Circle again, then extrude down scaling per joint (knee larger, ankle thinner). Foot: select 3 front faces, `E`, `S` `Z`; `Ctrl R` loops and scale on X so the foot narrows then widens at the toe. Push calves out in side view. Male look: V-taper with big shoulders and chest, strong jaw. Female: smaller neck (`Alt S`), rounder jaw, narrower shoulders with proportional editing, wider hips, thinner waist, slightly shorter (apply scale after).
  - Use when / pitfalls: check each step in front and side wireframe (`Z`). A first pass is "too straight", add chest, calf and spine curve at the end.

- **[low-poly] Clothes as loop-cut shells on the body, with material slots**: shirt, pants, shoes without separate meshes.
  - Steps: edit mode, `Ctrl R` a loop where the sleeve ends and a second one right next to it, `S` the extra loop (proportional editing off) to make a step, same for shirt hem and trouser cuff. Select the area with `Alt` and `Shift Alt` clicks in face mode, then `Alt S` to thicken it over the skin. Materials: Material tab, delete the grey material (minus), `+` new slot > New (name "shirt"), set Base Color and drag Roughness up. In Edit mode select the faces, pick the slot, press Assign. Add another slot for skin, assign arms/hands/head; repeat for pants, shoes. Select a whole material group with `L` over it, then in the "Select Linked" panel switch Delimit to Material.
  - Use when / pitfalls: the same material in two characters means editing one changes both; click the duplicate-material (paper) icon beside the name to make a separate copy ("shirt blue", "black pants"). Typing a name that exists gives ".001". Switch Viewport Shading to Material Preview (`Z` pie) to see colours.

- **[low-poly] Hair, vest and apron by knife cut + Extrude Faces Along Normals**: thickened shells from existing faces.
  - Steps: edit mode, `K` knife tool, click the corners of the hairline across faces, `Enter` to confirm (no clicking through to "cut through" needed on the surface). Face select, `Shift` click every hair face (missing one leaves a bald patch, fix by `X` > Faces on the odd faces and `F` to refill). `Ctrl F` (Face menu) > Extrude Faces Along Normals, drag to thickness (`Shift` for fine). Alternative: `E` then right click to cancel the move, then `Alt S`. Assign a new material (hair, vest, apron). Long hair: select the hair bottom faces, `E` down, `G` to shape. Vest and apron use the same knife + select + Extrude Along Normals + assign pattern; apron straps use a knife cut plus assigning the material, pockets are a face `E` then `S` down. The vest/pouches reuse the same recipe.
  - Use when / pitfalls: plain `E` on many faces extrudes each face its own way: use Along Normals.

- **[low-poly] Accessories: belt, pouches, buckle, badge, handcuffs**: props built from primitives and the character's own faces.
  - Steps: belt = two `Ctrl R` loops side by side, `S` the inner loop to a shell, assign black. Pouch = add a cube in edit mode (`Shift A` > Cube inside the mesh), turn Mirror Clipping OFF first so the cube does not snap to the mirror plane, scale and place, turn Clipping back on; `Ctrl R` plus extrude a face and edge slide for a flap. Duplicate with `L` (Delimit Seam to select linked), `Shift D`, rotate. Buckle = `Shift D` a belt face, flatten, extrude into the belt; if shading looks dark the normals are flipped: `L` over it then `Shift N` (Recalculate Outside). Gold: Base Color gold, Metallic 1, Roughness down. Badge = a separate object (add in Object mode, scale `Y` thin, `Ctrl R` loop, scale the loop up in Z), shaped by moving faces so it curves over the chest; duplicate for the shoulder; materials metallic grey. Handcuffs = `Shift A` > Circle, tweak the Adjust Last Operation panel Vertices 8 (low poly), fill by extruding, `E` `S` to make a ring, `Shift D` for the pair.
  - Use when / pitfalls: do this before applying the Mirror modifier; keep tiny objects separate when they should not mirror, then Join.

- **[low-poly] Hats from an 8-sided cylinder (police cap, chef hat)**: low-poly hats with a merged top.
  - Steps: `Shift A` > Cylinder, Adjust Last Operation Vertices 8. Scale and place on the head. Face select the top face, `E` up, `E` `S` to taper stage after stage; to close a crown extrude and `S` `0` Enter, then `A` and `M` > By Distance to merge the doubled vertices (it reports how many it removed). Brim: select 4 front faces, `E`, flatten by selecting edges and `G` `G`, then merge by distance. Add a cap badge: small cylinder flattened and rotated on the front, `K` knife one cut so it can bend, move the two edge faces back with `G` `Y` to wrap the brim curve, assign gold. Chef hat = cylinder with five `E` `S` steps to a puffy top, then `Ctrl B` a small bevel at the base.
  - Use when / pitfalls: always merge by distance after scaling to zero, otherwise stacked vertices break shading.

- **[low-poly] Finishing: apply Mirror, then join all parts into one mesh**: one object per character.
  - Steps: select the body, Modifier > Mirror dropdown > Apply (after this edits no longer mirror), then select the accessories first and the body last, `Ctrl J` (Join). Joining before applying copies the mirror onto the accessory. Rename in the Outliner (double click).
  - Use when / pitfalls: apply only after all modeling is done; join a hat only after the character mirror is applied.
