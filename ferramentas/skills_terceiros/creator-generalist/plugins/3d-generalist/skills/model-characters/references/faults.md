# Low-Poly Character Fault Catalog & Fixes (Blender, Three.js, 67js)

Check every character build against this fault table before delivering renders, GLBs, or scene recipes.

| # | Symptom / Visual Fault | Root Cause | Fix (Blender / Three.js / 67js) |
|---|---|---|---|
| **1** | **Colors look washed-out, grey, or muddy compared to the 2D reference** | Blender defaults to `AgX` or `Filmic` View Transform and lit `Principled BSDF`; Three.js defaults to tone-mapping or wrong texture `colorSpace`; 67js defaults to `aces` view transform on lit materials. | **Blender:** Route texture into `Emission (Strength = 1.0)` and set `Color Management -> View Transform = Standard`.<br>**Three.js:** Use `MeshBasicMaterial`, set `texture.colorSpace = THREE.SRGBColorSpace`, and `renderer.toneMapping = THREE.NoToneMapping`.<br>**67js:** Set `tag: "unlit"` on flat materials and `environment.viewTransform: "neutral"`. |
| **2** | **Centerline crease, pinch, or double faces along $X = 0$** | Leftover internal face on the mirror plane, or `Clipping` was disabled on the Mirror Modifier when moving center vertices. | Delete all faces lying on $X = 0$ before mirroring. Enable `Clipping` on the Mirror Modifier (`mergeThreshold: 0.001` in 67js `mirror` stack op). Run `check_character.py` to detect internal/non-manifold faces. |
| **3** | **Hair spikes, bangs, or jacket collar stretch when the arm moves** | Automatic weights (`Bone Heat`) bled from `DEF-upper_arm` / `shoulder` onto nearby hair and collar vertices, or `Auto Normalize` was off during Weight Paint. | Enable **`Auto Normalize`** and **`Flat` brush falloff**. Flood hair and head `100%` (`1.0`) to `DEF-spine.006` (`head` bone), and flood jacket collar `100%` to `DEF-spine.002` / `chest`. |
| **4** | **Vertex explodes or deforms twice as far as the bone** | Total skin weights on the vertex exceed `1.0` ($\sum w_i > 1.0$) because `Auto Normalize` was unchecked while painting multiple bones. | Run `Normalize All` in Blender (`Weights -> Normalize All`, lock active group), and keep `Auto Normalize` checked. `check_character.py` fails any mesh with $\|\sum w_i - 1.0\| > 0.01$. |
| **5** | **Knees bend backward (bird-leg) or elbows fold forward under IK** | Leg or arm bones were modeled and rigged in a dead-straight $180^\circ$ vertical/horizontal line. | Pre-bend the knee vertex loop and bone joint **forward** ($+2\text{ cm}$) and the elbow **backward** ($-2\text{ cm}$) in rest pose. In `67js`, verify `scene_inspect` reports zero `jointAxisProblems` (`straight-chain`, `knee-bends-backward`, `elbow-bends-forward`). |
| **6** | **2D face rig rapidly scrolls through all 6 expressions during a blink** | Keyframes on `eye_control` / `mouth_control` use Bezier (`SMOOTH`) or `LINEAR` interpolation instead of stepped keys. | Select all facial controller keyframes and set interpolation to **`Constant` (`T -> Constant` in Blender; `STEP` in 67js; `THREE.InterpolateDiscrete` in Three.js)**. |
| **7** | **3D low-poly iris clips out through the side of the cheek/temple when looking sideways** | The floating iris quad was duplicated at the full size of the eye socket, or X-Axis Mirror was left on while sliding edges. | Turn **OFF** X-Axis Mirror, select the perimeter edges of `iris.L` and `iris.R`, and **Edge Slide (`G -> G`)** inward so each plane tightly bounds only the painted iris circle. |
| **8** | **Project from View UVs overlap or distort across the mirror seam** | Mirror Modifier's `On Cage` / `Edit Mode` preview was left enabled while running `U -> Project from View`. | Disable the Mirror Modifier's Edit Mode preview toggle before unwrapping planar groups; only apply Mirror before unwrapping when creating asymmetric clothing or hair details. |
| **9** | **Knee pad or sock stripe stretches down the entire shin** | The leg cylinder only had 1 loop cut at the knee, so the UV quad spans the entire lower leg. | Add **2 support loop cuts** closely framing the knee (one just above, one just below). Unwrap only that narrow middle quad ring to the knee detail on the atlas. |
| **10** | **Cyclic walk/idle animation has a visible 1-frame hitch/pause at the loop point** | Frame `1` was copied to the final frame `N` (e.g., Frame `25`) instead of Frame `N + 1` (`Frame 26`), playing the start pose twice in a row. | Paste the Frame `1` loop key at **Frame `N + 1`**, set the playback/render range to `1..N`, enable `Make Cyclic` (`Shift+E`) in the Graph Editor, and set handles to `V -> Automatic`. |
| **11** | **Gaps visible inside neck collar, shorts cuffs, or under the chin** | Missing cavity faces or unmapped underside faces. | Extrude the jaw underside back to the 3-vertex neck; inset and extrude the torso neck hole downward; map all underside/cavity faces (`jaw_under`, `neck`, `inner_cuff`) to the **dark shadow swatch** on the atlas. |
| **12** | **Texture looks upside-down on a Three.js GLB mesh** | `texture.flipY` was left at Three.js's default `true` when replacing a `GLTFLoader` material map. | Always set `texture.flipY = false` and `texture.colorSpace = THREE.SRGBColorSpace` when assigning an external texture to a glTF/GLB mesh in Three.js. |
| **13** | **Box head with a flat face plate: the face reads as a mask on a block, eyes painted on one flat quad** | The head was built as a cube with one front quad. The series builds a hair shell plus a knifed face patch pulled into a profile (Parts 4 to 6). | Rebuild per `head-and-face.md`: patch with pointed nose, brow, cheek and jaw steps matched in the side view, under-jaw faces, hair bangs and side locks covering every bare box edge. Check a three-quarter view. |
| **14** | **Face looks derpy: eyes small, too high or too far apart** | Eyes were placed by eye instead of measured against the reference. | Measure eye width, eye height and gap on the reference, overlay front and side stills at 50 percent, then scale the face UV island wider and bigger (Part 8 end). |
| **15** | **Hair is bulky blocks, hood or head accessory is hidden** | Hair chunks left as thick boxes and the hood was never built as its own chunk. | Taper hair chunks to the drawn silhouette with M At Center and F fills. Build the hood from the turnaround in front, side and back, then orbit to check it shows. |
| **16** | **Pixelated or smeared texture on an angled face** | Project from View was run at a harsh camera angle, or the texture was painted before the UV existed. | Project from an orthographic view, move UV vertices to cut distortion, make the UV before painting (Part 8). |
