## 5.x names

- Pose Library is asset-based (3.0+): Asset Browser in Pose Mode, Asset > Create Pose Asset.
- Eevee motion blur is native since 2.91. In Eevee Next (4.2+) motion blur lives in Render Properties and may be a compositor or render-time effect, check the panel.
- "Look: Very High Contrast" belongs to Filmic. With AgX (4.0+) pick a High Contrast look instead.
- Shape key Value, light Power and similar fields still take `#frame` as a quick driver.
- Bake Action is F3 "Bake Action", Visual Keying and Overwrite as before.
- Copy Global Transform is built in (Global Transform), the paid Copy World Space does the same.
- Grease Pencil animation changed in 4.3 (GPv3), see `geometry-nodes.md`.

## Keyframing and graph editor

- **Basics**: I inserts keys, Auto Keying records (turn off after), T interpolation (Linear, Bounce, Back, Constant), Ctrl+E easing, V handle type. Output: set folder, PNG sequence, View > Viewport Render Animation to include overlays. Compile in Video Editing with Add Image Strip, FFmpeg MP4 H.264. Image sequences can resume. Animated metal wave: Plane 50 cuts, Displace Clouds with an Empty rotated 360 on Y, metallic 1, roughness 0.1.
- **Rig posing and loop keys**: Ctrl+Tab Pose Mode. R X X local axis. Copy Pose Ctrl+C, Paste Flipped Ctrl+Shift+V. Dope Sheet: Only Show Selected, Ctrl+Tab Graph Editor, Normalize, N values. Loop: F-Curve Modifiers > Cycles (Repeat Mirrored), copy modifiers, paste with Replace Existing. Offset hand and head keys by 2 frames. Easing: scale handles with Individual Centers. Save in Action Editor with Fake User.
- **Overshoot and anticipation**: Select all keys, T > Bezier (poses were Constant). Copy each pose to 3 frames before the next key. Overshoot: Shift+D the key 3 frames later, V > Automatic on the original, Shift+R repeats. Anticipation: duplicate 3 frames earlier, earlier pose Automatic. Alternative: Pose > In-Betweens > Push (Ctrl+E). Follow-through: G then 1 pushes head or hand keys one frame later. Graph Editor V > Auto Clamped flattens handles, Automatic gives elastic bounce.
- **Short-film tricks**: Duplicate last key, V Automatic for overshoot. Beat sync: frames per beat = fps x 60 / BPM (24 x 60 / 160 = 9). Stretchy rig with stretch-to tweak bones. Pick-ups via Child Of with animated influence, fix the jump with Copy Global Transform. NLA for looping bob layers. Model swap with hidden-keyframe transition.
- **Animating from a reference clip**: Load in the image editor, key extreme poses, layered approach (hips, arms, head separate), each dance as a separate Action combined in the NLA, Simplify for viewport speed, Global Transform for foot placement, Wiggle Bones for floppy parts, FK when the chest pops, motion blur.
- **Cycle looping**: Select all curves (Alt+H unhide), Shift+E > Make Cyclic, or N > Modifiers > Cycles then copy and paste. Desync head bob with L on a channel, offset 2 to 3 frames.

- **Bounce easing from two keys**: Dope Sheet, A, T > Bounce (between Back and Elastic). Ctrl+E picks the easing: Ease In puts the bounces at the start, Automatic Easing (top entry) at the end. Bounce and Elastic interpolation exist in 5.2 (measured).
- **Stop motion with Stepped Interpolation**: Graph Editor, A, Ctrl+Shift+M > Stepped Interpolation (applies to all selected curves). N > Modifiers > Step Size 2 for twos or 4 for fours (5.2 default is 2); each active curve has its own settings; tick the modifier header checkbox to turn it off per curve.
- **Drivers from the frame number, no keys**: click a rotation field, type `#frame/8` (minute hand) and `#frame/96` (hour hand), Enter (the field turns purple). The `#` makes a driver, and dividing converts frames to radians. Positive Y rotation turned clockwise seen from the front for that model, so check the sign.
- **Constant spin and Linear Extrapolation**: set the keys to Linear (T > Linear), then Shift+E > Linear Extrapolation for a fan that keeps spinning; Shift+E > Make Cyclic for a bob that repeats.
- **Motion paths**: Object properties > Motion Paths > Calculate; Display > Keyframe Numbers; move the object at the peak frame (G Z), I to key, click Update.

## Walk cycle and foot slide

- **Walk cycle from four poses (FK)**: Link the rig (File > Link), F3 Make Library Override. Disable IK and copy rotation on arms. 30 fps, one step = 20 frames, cycle 40. Frame 0 contact: torso lowered, front heel rotated on local X, key feet and torso. Ctrl+C summary, Ctrl+Shift+V at frame 20, copy frame 0 to 40 with Ctrl+V. Passing (10): Alt+R, Alt+G feet, back foot up (right-click channel > Insert Single Keyframe). Down (5): hips lowest. Up (15): hips highest. Hips rotate toward the lead foot, shoulders counter-rotate, head bobs, arms last, hands follow through. Graph Editor: Z rotation channel, Shift+H isolate, scale Y with Bounding Box Centre pivot. Key only the channels you move.
- **No foot slide (constant speed)**: Planted heel Y flat between contacts (Free handles with V, S 0). Shift+S Cursor to Selected marks heel. Eyeball: key root Y at 0 and 20, T Linear. Exact: copy the heel Y at frame 20 (Ctrl+C on the field) into the root Y key, Linear. Looping travel: Cycles modifier Repeat with Offset, or Shift+E Linear Extrapolation. Mirror leg motion: delete second foot keys, copy first, paste flipped, G X 20 frames. Mute the root F-curve to keep the camera still. Moving the Armature object instead of the root bone rotates around its origin, better for curves.
- **Foot slip with root and Global Transform**: Key poses at 24 fps, Shift+E > Make Cyclic. Root key at 0 and 100, Linear, planted foot curves Linear. Match speed: cursor at the planted foot, move the root end key until the foot stays on it (about 1.18 m per cycle). For turns and steps copy the foot with Global Transform, paste each frame with Auto Key on, release to move. NLA playback scale keeps feet planted when speeding or slowing.
- **Heel and weight curves**: Heel curve flat while planted then a slight overshoot on leaving. Hips drop faster than they rise. Search "zquat" in the channel filter to delete Z rotation channels for silly walks.

## NLA and actions

- **NLA layers**: Action Editor, save actions with the shield, Push Down makes strips. G move, S scale, Y split, Shift+D duplicate, Tab edits a strip (hover NLA). N: Extrapolation (Hold, Hold Forward, Nothing), Blending (Replace, Combine, Add, Subtract, Multiply). Actions interact only on the same bones, so key only a layer's bones. Combine measures offset from rest pose so start and end an additive action on rest. Turn off Only Show Selected in the action editor. Blend In and Out, Animated Influence, Animated Strip Time (Linear), Playback Scale, Repeat, Reverse, Cycles modifier for loops, Stepped Interpolation modifier for stop motion. Bake Action with Only Selected Bones off. Transition into a walk: new action from rest pose using Global Transform to lock feet. Page Up and Down move tracks.
- **Character pipeline**: Script, audio, pick takes in Resolve. Lip sync in its own Action with audio in the Sequencer (waveform, Audio Scrubbing, Sync to Audio), mouth shapes as pose assets, keys 2 to 3 frames apart and slightly early. Body: new Action, constant keys then Bezier, copy a pose and paste it 5 frames later for consistent easing. Layer actions in the NLA, wiggle bones baked to a separate action. Link the character with a Library Override, append props you edit. Render in Eevee.
- **Pose library and visualizer**: Asset Browser in Pose Mode, Create Pose Asset (mouth shapes). Visualizer add-on (GitHub zip) for audio bars, Generate, copy a bar's scale as a driver.

## Camera

- **Camera rig tricks**: Pivot: Empty Plain Axes, Alt+G camera, pull back, camera then empty Ctrl+P, rotate the empty to orbit, scale to zoom, DoF focus on the empty. Shift X and Y keep perspective. Clip Start 0.05. Tracking: Damped Track (-Z), second constraint with animated influence switches focus. Follow without rotating: Copy Location (Offset) or parent without inverse. Handheld: record it with Walk Navigation (entry below), then bake and smooth. Dolly zoom: focal 10 and pivot scale 1, then focal 50 and scale 5. Shake: single key, Noise modifier strength ~0.1. Switch: markers (M), select the camera, Ctrl+B Bind Camera to Markers. Ctrl+L Link Object Data shares lens.
- **Camera follows an object (Track To)**: select the camera, Object Constraints > Add Object Constraint > Tracking > Track To, Target = the object (Track Axis -Z, Up Y, Influence 1.0). It aims only, it does not move the camera. The target moves by keyframes.
- **Record a camera move by walking, then smooth it (Walk Navigation + Auto Keying)**: Select the camera, Numpad 0 for the camera view, Camera Lens 20 mm for a wide look. Move with View > Navigation > Walk Navigation (W A S D move, E up, Q down, mouse looks, G or Tab toggles gravity so the eye stays near 1.7 m, V jumps, Shift fast, Alt slow, left-click confirms). Quick start: Shift+` (`view3d.navigate`, Walk or Fly by Preferences > Navigation; the old fly key Shift+F is gone), or right-click the menu item > Assign Shortcut, or Add to Quick Favorites (Q) so it works on any keyboard layout. Record: Auto Keying on, Space to play, start Walk Navigation, move: a key lands on every recorded frame at the scene fps. Gaps and wobble: select all keys in a Graph Editor, bake, then smooth. 5.2 route: Key > Density > Bake Keyframes (`graph.bake_keys`, Shift+Alt+O, the old "Sample Keyframes") puts a key on every frame; then Key > Smooth > Smooth (Legacy) (`graph.smooth`, Alt+O, the old "Smooth Keys"), held many times (the video pressed it 34 to 88 times); Smooth (Gaussian) and Butterworth are newer alternatives. Pin both ends: insert a key on the first and last frame of the move before baking (Graph Editor Key > Insert > Available, or I > Available), else the ends slide. A new take is: delete the keys, walk again, a few seconds of smoothing. Works in every render engine and exports with the camera.
  Check: verified [View > Navigation menu at 0:46, dense keys and smoothed curves at 6:13 and 6:25 (1920x818, 30 fps, 690 frames, "Alt + O x88"), walk status bar]. The operator names and keys come from the 5.2.2 keymap. Rebuilt headless in 5.2.2 (180 frames, 6 channels): 276 recorded keys became 1080 after Bake Keyframes and 34 smooths cut the second difference of location from 0.0359 to 0.0035 (10x). Traps: a look-at Euler jumps 360 degrees between keys unless made compatible (`euler.make_compatible(previous)`), and the camera then spins; Graph Editor operators need the camera selected with Only Show Selected on. Version: "Sample Keyframes" moved to Density > Bake Keyframes; "Smooth Keys" is now labelled Smooth (Legacy).
- **Set up a camera shot in four steps**: Find the angle in the viewport, then either N sidebar > View tab > View Lock > Camera to View (tick it and keep navigating, the camera follows the view, untick when done), or once with View > Align View > Align Active Camera to View (Ctrl+Alt+Numpad0). Output Properties > Format > Resolution X and Y (portrait works). Camera Properties > Lens > Focal Length (default 50 mm). Tick Depth of Field, set Focus > Object, lower F-Stop to blur more.
  Check: verified [View Lock rows "To 3D Cursor" and "Camera to View" at 5.5 s, Lens panel and the Depth of Field box at 35.5 s, landscape then portrait frame at 11.5 and 25 s]. F-Stop and Focus fields too small to read, unverified. Rebuilt in 5.2.2: `view3d.camera_to_view` copied the view's location and rotation to the camera exactly; the DoF focus object must be inside the frame (mine on a foreground apple blurred the subject first try); 85 mm after the portrait switch crops hard, so recheck framing after any lens change. Version: unchanged in 5.2.
- **Camera on a curve with a separate look-at target (Follow Path + Track To)**: Prep: camera, lights and helpers in a "render" collection (C in the outliner); Lens 50 to 30 mm; Clip Start 0.01; Camera > Viewport Display > Passepartout 0.99 (1 blacks out all outside, 0.99 keeps it faintly selectable); 60 fps and a 21:9 resolution for smooth cinematic motion; Render Properties > Simplify > Max Subdivision 2 for a heavy sculpt; split the view and Home or View > Cameras > Frame Camera Bounds to work outside the camera. Target: Add > Empty > Circle, size 0.15, Object Properties > Viewport Display > In Front, named Camera Target. Camera constraints: Track To (Target = Camera Target, Track Axis -Z, Up Y) with Target Z ticked, so rotating the empty rolls the camera. Path: Add > Curve > Path, delete two points, shape it in Edit Mode (keep the distance to the subject steady). Add a Follow Path constraint on the camera, Target = Camera Path (Forward Y, Up Z; Fixed Position, Curve Radius, Follow Curve off); not Ctrl+P > Follow Path, which animates the path for you. Put Follow Path above Track To (position first, aim second). Start point: in Edit Mode Shift+S > Cursor to Selected on the first point, then the camera Shift+S > Selection to Cursor. Animate Follow Path > Offset: key -100 on the first frame and 0 on the last, select all keys, T > Linear for constant speed. Key the empty's location and rotation the same way, also Linear, or it eases while the camera does not. Curve Properties > Shape > Resolution Preview U to 64 (low values make a polygonal path). P in the timeline sets a preview range, Alt+P clears it; moving the keys of path and target together changes the timing.
  Check: verified [Track To and Follow Path panels at 11:05 and 13:20, Offset key and constraint stack at 17:30 and 20:00, Passepartout field and Focal 50 and Clip Start 0.1 at 5:00]. Rebuilt in 5.2.2 (120 frames, 3-point NURBS path): Offset -100 puts the camera at the END of the curve and 0 at the START, so keying -100 to 0 runs against the spline direction; key 0 to -100 to go start to end. Step per 10 frames was 0.722 to 0.723, constant with Linear. The target on the head kept it centred through the arc while the ears slid across it (parallax). Version: nothing renamed, constraint names are the same in 5.2.
- **Cut between shots with one camera (second Follow Path, swap influence)**: Duplicate the path (Shift+D) and move it to the other side of the subject. Duplicate the Follow Path constraint and point it at path two, keeping both above Track To (script: `constraints.move`). On the last frame of shot one key Influence 1 and 0; one frame later 0 and 1 (Auto Keying records it). Then key the new constraint's Offset, and the empty onto a new subject. Markers (M) with Bind Camera to Markers work too but pile up cameras; one camera with several constraints stays tidy. Bezier on the last keys eases a stop at the end.
  Check: verified [Follow Path 2, Influence 1.000 and constraint list at 20:00]. Rebuilt in 5.2.2: at frame 60 the camera sat on path one (0.04, -3.25, 1.80), at frame 61 on path two (4.00, 2.00, 2.40), a hard cut inside one frame. Bezier on influence would blend the two positions between.
- **Same move in other engines** (not run here, from each engine's docs): three.js `CatmullRomCurve3` with `camera.position.copy(curve.getPointAt(t))` (even arc length, so constant speed) and `camera.lookAt(target)`, easing `t` yourself. Godot: `Path3D` holding a `PathFollow3D` with the `Camera3D` as child, animate `progress_ratio` 0 to 1. Unity: Cinemachine Spline Dolly on a Cinemachine Camera with a Look At target, cut with Timeline or priorities. Unreal: Sequencer with a Camera Rig Rail and a Cine Camera Actor attached, key the rig's Current Position on Rail.
- **Turntable**: Parent camera to an Empty and rotate it.
- **Track To camera with a two-key orbit**: camera, Constraints tab, Add Track To, Target = the subject (or an empty to aim anywhere), Track Axis -Z, Up Y. Orbit: select the subject, Shift+S > Cursor to Selected, Add > Empty > Plain Axes, F2 name it `orbit`. Select the camera then Ctrl-click the empty, Ctrl+P > Object (Keep Transform). Frame 1: Item panel, hover Rotation, I. Frame 120: rotate the empty about Z (360 for a full turn), I. In the Graph Editor select the keys and T > Linear, or the turn eases in and out. Radius and height are set by moving the camera.
- **Camera shake**: the full Noise-modifier recipe (Strength 0.1, Scale 5, Phase 2 on a second axis) is "Camera shake with a Noise modifier" in `lighting-render-and-gn-recipes.md`.
- **Focus pull**: key the focus empty's location from the near subject to the far one (G Y). The camera does not move.

## Seamless loops

- **Rules**: Compare first and last frames (Shift+Left and Right). Linear (T) on everything that repeats. Rotation angle = 360 / segments. One loop distance = a multiple of the tile spacing. Start the timeline at 0.
- **Hex and triangle tunnel (2.83)**: Circle 6 verts, rotate X 90, scale 5, extrude Y 1 m, Alt+E along normals, Origin to Geometry. Array Object Offset with an Empty at Y -1 (count 6), Mirror. Empty Y rotation 0 to 60 Linear. Collection Instance every 10 m (60 m). Camera Y 0 to 60 Linear, clip end 500, focal 20, a plane on the camera hides the pop. Lights parented to the camera. Triangle: Array 50, rotation 360/50, camera Y rotation 0 to 360. Shader Mix Emission, Wave Object Y Greater Than. Bevel last.
- **Wave-grid loop with glowing points**: Plane scale 10 apply, subdivide 49. Wave modifier (offset -250, width 5, height 2, speed 0.2 so frames 0 and 200 match). Simple Deform Z 360. Ico Sphere (2) parented, plane Instancing > Vertices, hide plane. Emission, Object Info Random -> Color Ramp.
- **Milky rings (2.83)**: Plane 10, subdivide 100, Subdivision above, Displace with Empty (Object coords). Voronoi Chebychev, 13 alternating stops Constant then Linear, strength 0.1 to 0.2. Key Empty Z 0, 0.5 at 125, 0 at 250. Mirror, Array, Collection Instance offset 40 m, camera 0 to 40 Linear. Shading in `shading-and-textures.md`.
- **Scaling loop with nested collection instances (2.83)**: Circle with Skin. Collections OG and inst. Instance OG into inst, Shift+D, S 0.5, Shift+R to ~16. Key OG scale 1 at 0 and 2 at frame 50 Linear (Bezier with first handle Vector). Edit the original and all copies update. Move in Edit Mode so origins stay.
- **Instanced scenes**: Right-click a collection > Instance to Scene, duplicate at 10 m, key the camera exactly one spacing Linear.
- **Displaced bands loop**: Cube, Alt+M, extrude 20 on X, subdivide 25, Skin smooth, Subdivision, Ctrl+A flatten. Array Constant Y count 50. Displace Clouds Z with an Empty, placed after Array. Mask: vertex group + Vertex Weight Edit (Custom falloff, inverted), second texture Blend Spherical on another Empty. Key Empty rotation Y 0 to 360 over 250 Linear. Apply Array and P > By Loose Parts for Object Info Random colours.
- **Cave layers**: Pivot Empty with camera, plane X 90, Array Z 0.1 count 50, Solidify, Displace Clouds local Y, Simple Deform Bend 360 with an Empty, key pivot rotation X 0 to -360 over 250.
- **Worm loop (Displace + Follow Path)**: Displace above Skin, Clouds with Object coords driven by an Empty that has Follow Path on a Bezier Circle (Offset 0 to 100 Linear). Arrays Constant X 1 count 10, X 0.5 + Z 1.25, Y 2.5 for staggered grid. Move ground 10 m in Y (multiple of 2.5) Linear.

## Commotion and offsetting

- **Commotion (free add-on)**: Install zip from GitHub, N panel tab. Prepare: plane subdivided 19, Edge Split, Individual Origins, P > By Loose Parts, Origin to Center of Mass, M to a collection, key location (1, 15 up, 30). Select all > Offset Animation. Offset (frames, below 1 allowed), Threshold, sort by Cursor (starts at 3D cursor, offset starts at the playhead, Shift+S cursor to origin), Name, Random, Multi-Offset (effectors collection of empties), Proximity.
- **Proximity effector, shape keys, materials**: Proximity Effector with animated and effectors collections, Location, Rotation, Scale start and end, Falloff, Trail, Bake. Shape keys: Basis + Key 1, key it, Animation Utilities > Copy, offset with shape keys ticked. Materials: Make Single User > Materials, animate Base Color, then offset. Linked materials cannot offset.
- **Looping offset**: Plane Subdivision (Simple), Decimate Collapse 0.5, Edge Split (0), Smooth, Solidify 0.2, Modifier Tools Apply All, P > Loose Parts, Origin to Center of Mass. Key 0, 25 up, 50 back. Graph Editor Normalize, Cycles modifier pasted with Replace Existing and Only Active off. Offset 0.1 at frame 0, offset 0 and rerun to restore.

## Empties, parenting and hooks

Short rigging-by-empty tricks. `Child Of` scale toggles, `Pose.use_auto_ik`, the Hook falloff types and the modifier types below exist in 5.2 (measured 2026-11-08); the click paths were heard, not run.

- **Group pivot with one empty**: Shift+S > Cursor to Selected on the pivot spot, Add > Empty. Select all the parts, Shift-select the empty last, Ctrl+P > Object (or Object Keep Transform to stay put). Unparent with Alt+P > Clear Parent, Keep Transform.
- **Adjustable hinge and nested orbits**: select the door, then Shift-select an empty `hinge` last (the parent), Ctrl+P > Object; rotating the empty swings the door. To move the empty alone, viewport Options (top right) > Transform > Affect Only > Parents, and turn it off again afterwards. Nested orbits: `moon` under `moon orbit`; the planet and `moon orbit` under `main orbit` (children first, parent last, Ctrl+P > Object).
- **Child Of without inheriting scale, and copying a family**: Object Constraints > Add > Child Of, target the empty, Set Inverse, untick Scale X, Y, Z; Influence 0 releases the object. Copy a parent and its children: right-click the empty in the Outliner > Select Hierarchy, Shift+D (Alt+D keeps the mesh data linked). Key the parent's rotation (I over Rotation Z in the Item panel) and the children follow.
- **Hook to a new object with falloff**: Edit Mode, select all vertices, Ctrl+H > Hook to New Object (adds an empty and a Hook modifier). Modifier > Falloff Smooth, drag Radius (0 means no change); Strength scales the pull. Select all vertices first, because falloff only fades vertices the hook owns.
- **Copy as New Driver**: right-click a value > Copy as New Driver, right-click the target field > Paste Driver.
- **Empties that drive modifiers**: Array Object Offset (empty rotation plus Z location makes a spiral staircase; scale below 1 shrinks each copy; two-axis rotation makes a helix); Mirror modifier Mirror Object (an empty's rotation mirrors across a diagonal); Simple Deform Origin (bend, twist, taper or stretch around the empty); Displace with Texture Coordinates Object and the empty as object (slide or keyframe the pattern; subdivide first, because Displace moves only existing vertices).
- **Decal or logo placed by an empty (no UVs)**: Shader Editor, Texture Coordinate Object = the empty, its Object output into the Image Texture Vector, Extension Clip so it appears once. Move, rotate and scale the empty to place the decal; scaling the empty down enlarges the decal.
- **Collection instances for repeated assemblies**: select the parts, M > New Collection; Add > Collection Instance > pick it; Shift+D the instance empty many times. Edit the source collection once and every copy updates at almost no memory cost. Set the collection's Instance Offset to the model's base so copies sit on the ground.
- **Force fields on empties, driven by empties**: Physics tab > Force Field type Force, Wind, Vortex, Turbulence, Magnetic, Drag or Curve Guide. Wind blows along the empty's local Z; negative Strength pulls; Falloff Shape point, line, plane or surface with Max Distance; Field Weights > Effector Collection limits which fields a system reads. Drivers: right-click a field > Add Driver, Object = an empty, Type Transform Channel, Z Location; remap in the Drivers editor or an expression such as `var*0.1` or `var+2`; drive Roughness, Array Count or modifier strength.
