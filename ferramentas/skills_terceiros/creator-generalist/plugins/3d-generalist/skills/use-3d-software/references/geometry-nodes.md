## 5.x names (read first)

- Align Euler to Vector -> Align Rotation to Vector. Rotate Euler -> Rotate Rotation. Euler sockets became Rotation sockets in 4.x, so no radians conversion is needed when a Rotation socket is used.
- Transfer Attribute -> Sample Index and Sample Nearest (4.0). Nearest index into Sample Index gives the old Index mode, Geometry Proximity still exists.
- Mix RGB -> Mix (Color), plus Mix (Float) and Mix (Vector) since 3.4.
- Separate RGB / Combine RGB -> Separate Color / Combine Color.
- Point Instance, Point Distribute, Point Scale, Attribute Randomize (2.93) -> Instance on Points, Distribute Points on Faces, Scale Instances, Random Value.
- Curve Parameter (3.0) -> Spline Parameter plus Spline Length.
- Boolean (Difference) -> Mesh Boolean. Remove Doubles -> Merge by Distance.
- Auto Smooth checkbox (removed 4.1) -> Smooth by Angle modifier or Set Shade Smooth with an angle setting.
- Musgrave Texture -> Noise Texture with a Type dropdown (4.1).
- Repeat Zone (4.0) and Simulation Zone (3.6+) replace duplicated node groups for repeated steps.
- Grease Pencil is GPv3 from 4.3. Grease Pencil to Curves and Interpolate Curves are the useful nodes.
- Set Position + Noise replaces the Displace modifier. Duplicate Elements, Blur Attribute, Sample Index and Scale Elements + Extrude Mesh replace older multi-node setups.
- Noise distortion: use the Noise Color output, not Factor (Factor smears diagonally).
- Measured in 5.2.2 (2026-11-08): Mesh to Volume `Resolution Mode` (Amount, Size) and Distribute Points in Volume `Mode` (Random, Grid) are menu input sockets, not node properties. Vector Math's output socket is `Vector`. Noise Texture gains Offset and Gain inputs. Geometry Proximity `Target Element` is Points, Edges or Faces; Distribute Points on Faces is Random or Poisson Disk.

## Basics and rules

- **Setup and rules**: Select the object, Geometry Nodes workspace, New (or Add Modifier > Geometry Nodes). Group Input is the original mesh, Group Output is the result. Primitives can replace Group Input. Shift A or S searches nodes. Alt-drag a node over a link to insert it. Value feeds one number to many sockets, Combine XYZ drives one axis. Drag the empty Group Input socket onto a field to expose it, N > Group tab renames and sets type, default, min, max. Shield icon saves a group. Red link = incompatible socket (diamond fields cannot go into circle sockets). Set Material nearest the output wins, so put it before Join Geometry to colour parts differently.
- **Fields vs attributes, Capture Attribute, morph**: Circle sockets are data, diamond sockets are fields. Inspect with a Viewer (Ctrl+Shift+click) and the Spreadsheet. Set Position Offset already adds. Normal x Noise displaces along normals like Displace. Capture Attribute stores a value at one point in the graph and needs geometry in and out. Fields evaluate on whatever geometry is upstream of the node that uses them, so after a geometry change (for example Mesh to Points) capture first. Morph: capture Position of mesh A, Set Position with Mix (Vector) of Position and the captured value, factor 0 to 1. Both meshes need enough points.
- **Instances vs realize**: Realize Instances is needed before Set Position deformation, before Distribute Points on instanced geometry (otherwise every copy gets identical points) and for unique object texture coordinates. Per-instance shader variety works unrealized through Object Info Random into Mapping location or Noise 4D W (x500) or Map Range. Cost check: Overlays > Timings. Realizing raised 4 ms to 11 ms in the demo, so keep it last.
- **Viewport vs render density**: Is Viewport node into Switch (Float) with a coarse value (voxel 0.3, density 100) and a fine one for render (0.05 to 0.01, density 100000). Use for Mesh to Volume, Points to Volume, fuzz.
- **Reusable groups**: Ctrl+G group, Tab to enter, N > Group to rename inputs, number button = users (press for single user before editing one copy), Ctrl+Shift+D duplicates with connections, F auto-links matching sockets, Shift+G > Type selects inputs, Ctrl+H hides unused sockets. Share to other files with File > Append > Node Tree and Fake User.
- **Collection switcher**: Collection in Geometry Nodes with Separate Children and Reset Children on, Delete Geometry (Domain Instance) with Compare (Not Equal) of Index and a Group Input integer. Use on a separate object for swapping eyes, mouths, hair.

## Instancing and scattering

- **Instance on points aligned and scaled to the surface**: Move the shape up 1 m in Edit Mode so origin sits at the base. Drag it into the tree (Object Info, As Instance, Original). Join Geometry with the base. Rotation: Normal into Align Rotation to Vector (axis Z). Scale: Face Area -> Square Root -> Multiply. Subdivision Surface before Instance on Points makes instance size follow face area. Scale Instances pivots at the instance origin, Scale Elements at the mesh centre.
- **Instance on faces**: Mesh to Points (Faces) feeding Instance on Points. Put Capture Attribute (domain Face, Vector for Normal, Float for Face Area) before Mesh to Points and plug the captured outputs downstream.
- **Random scale and rotation**: Grid base. Scale Instances scale from Random Value (Float uniform, or Combine XYZ with X,Y = 1 and Random in Z). Combine XYZ defaults are 0 so reset axes to 1. Use To Radians to type degrees, or tau for 360.
- **Scatter a collection (Pick Instance)**: Collection Info with Separate Children and Reset Children, Instance on Points Pick Instance on, Instance Index = Random Value (Integer), seed reshuffles, index wraps.
- **Poisson Disk scatter and weight-paint density**: Distribute Points on Faces, Poisson Disk with Distance Min (a diameter), Density Max, Density Factor. Its Rotation output plugs into Instance on Points. Paint density: drag the empty Group Input socket into Density Factor, pick a vertex group in the modifier panel. Weight maxes at 1, so Multiply to get real density. Vertex groups work only on original input geometry.
- **Recursive fractal with groups**: Cone (3 vertices) Instance on Points on itself, group with only Points, Instance and Scale, duplicate groups, F to connect, Scale Elements between. Over 6 nested groups add Realize Instances. In 5.x prefer a Repeat Zone.
- **Crystal generator**: Cylinder 8 vertices, loop cut, bevel, scale tips to 0 on Z, Merge by Distance. Distribute Points on Faces, Instance on Points using Group Input geometry as the instance, Join with original. Rotation Random Value Vector (-tau, tau). Scale from Noise Color via Separate Color into two Map Ranges (XY and Z). Second layer: Realize Instances, distribute again, scale 0.2. Distort with Set Position Normal x Noise. Glass in Cycles: Glass BSDF IOR 1.3, Transmission and Total bounces up to 1024, samples 2048.
- **Index-driven per-instance animation**: Index / Attribute Statistic max (Domain Instance) gives a start offset, add Scene Time Seconds / speed, Modulo 1, Map Range From Max = 1 / visible count, Float Curve for in and out into Scale Instances. One Value feeds both the speed and Map Range. Add +1 to the max to avoid popping at frame 1. Test on a Mesh Line first. Index counts per instance so statistics must use the instance domain. Sparkles: Cube -> Extrude Mesh (Individual, 0.01 / 0.1) -> Subdivision Surface, Distribute (Poisson 0.2, density 250) with Set Position offset Normal x scale, Emission about 5, glow needs Compositor Glare in Eevee Next.
- **Footstep generator**: Add-on Import Images as Planes for a transparent footprint PNG. Draw curve with Draw tool on Surface. Resample Curve, Instance on Points, Translate Instances Z 0.02, rotation from Curve Tangent via Align Rotation to Vector (axis Y, pivot Z). Alternate with Separate Geometry (Instances) on Index modulo 2, offset X by a Value, Scale Instances X -1 on one side. Growth: Delete Geometry (Instance) where Index <= Max Index x factor (+1), key the factor 0 to 1.
- **Instanced cubes boolean-cut from a cube (2.93 names)**: Instance cubes on the vertices, Mesh Boolean Difference with the original in the first input, instances in the second. Animate with `#frame`/100. High density with Boolean crashes.
- **Minecraft-style builds**: BlockBlender add-on converts meshes. House scatter uses Distribute Points on Faces, Instance on Points with a collection, rotation through Snap (45). Cave columns: Mesh to Volume, Distribute Points in Volume, Volume to Mesh, delete by Noise threshold, colour by Store Named Attribute, tops by Normal dot (Z=1). Trees: Skin modifier then Fill. Model must exceed 1 m. See `workflow-and-addons.md` for BlockBlender install and export.
- **Mesh to blocks in nodes (BlockBlender approach)**: Mesh to Volume (Size), Distribute Points in Volume (Grid), Instance on Points with Cube, same voxel size, spacing and scale. Sample image colour per point, pick the nearest block by 3D RGB distance, or Sample Nearest over blocks sorted as points in RGB or HSV. Needs an image texture, bake procedural colours first.

## Points, volumes and meshes from points

- **Any mesh into LEGO bricks or cubes (3.4+)**: Mesh to Volume (Fill Volume off, Resolution Mode Size, voxel = brick size, Interior Bandwidth = size x2), Distribute Points in Volume (Grid, spacing = same value), Instance on Points with Cube then the brick (scale = value, Z x1.23 for stacking). Apply rotation on the source if bricks are sideways. Mesh must be watertight. Colour transfer: Named Attribute (UVMap, Vector) -> Sample Index (Face Corner) with Sample Nearest -> Store Named Attribute (Vector, Instance domain, "UVMap") -> Set Material. Shader: Attribute node (name UVMap, type Instancer) into the image vector. One material per model. Shell variant: Fill Volume off, interior and exterior bands.
- **Volume Cube to mesh (3.3+)**: Delete Group Input, Volume Cube -> Volume to Mesh. Voronoi Distance into Density, subtract to enlarge holes (cheese, caves, Noise detail low scale 2). Resolution 32. Smooth with Subdivision Surface node or the Smooth modifier. 4D Noise with Scene Time into W animates. Sphere variant: Gradient Spherical into Density. Mesh to Volume then Volume to Mesh works as a Remesh that merges joined objects.
- **Distribute Points in Volume for shrubs and clouds**: Mesh to Volume, Distribute Points in Volume (Random density or Grid). Shrub: instance a leaf with Random Value (tau, tau). Clouds: Set Position offset (Noise Color - 0.5) x scale, Points to Volume (radius from noise, max 0.3), Set Material with Principled Volume. Eevee volumetric shadows on, tile size 4 or 2. Very small voxels crash Blender.
- **Noise-driven points snapped onto a surface (3.0+)**: Modifier on a plane, target mesh via Object Info (Relative). Distribute Points on Faces, Set Position Offset = Noise 4D (Detail 0) - 0.5 x strength, W from Scene Time / n. Second Set Position Position = Geometry Proximity (target, Faces). Instance with distribute Rotation. Smooth the target if edges jitter.
- **Noise cloud from a mesh line**: Mesh Line (100) -> Mesh to Points, Noise into Position (not Offset) with low offset (1 gives threads, 0.99 fewer squashes). Voronoi (4D, Smooth F1) as an alternative.
- **Empty-controlled spread and normal alignment**: Object Info of an empty (Relative), add its Location to the noise coordinate, scale to noise scale, Vector Rotate from its rotation. Align points via Sample Index normal into Align Rotation to Vector (Z). Share with Append Node Tree and Fake User.
- **Infinite shape generator (3.3+)**: No Group Input. Points node (count 200) -> Set Position offset 4D Noise Color (W = Index, detail 0, scale 10 to 15) - 0.5 x Scale (Divide 1000). Points to Volume (Size, voxel 0.1, radius at least 0.1) -> Volume to Mesh, smooth about 80 passes. Symmetry: Transform scale -1 joined, Capture Index into the Random Value ID. Change seed with Math Add on Index.
- **Smooth by averaging edge vertices**: Set Position Position = (Edge Vertices Position 1 + 2) / 2. Chain 10, group, duplicate for 100 passes. Mix (Vector) with captured Position controls strength. Use only where a Blur Attribute node is not available (5.x has Blur Attribute, prefer it).
- **Face scaling with loopable noise**: Ico Sphere (4 to 5) -> Dual Mesh -> Split Edges. Capture Position (Face), Set Position Mix (Vector) of Position and captured, factor from Noise Factor -> Map Range (0.4 to 0.6, To Max 0.9). Solidify after. Loop: two Noise textures with identical settings except W, mixed by a keyed factor, second W keyed -1 to 0, Linear interpolation.
- **Shortest Edge Paths mazes and growth (3.3+)**: Subdivided plane, Shortest Edge Paths (Next Vertex Index) -> Edge Paths to Curves. End Vertex = Compare Index equal 0 (several ends: Less Than or Boolean Or, or a vertex group). Edge Cost = Random Value. Trim Curve start animates growth. Curve to Mesh with Quadrilateral 0.01. On spheres reduce points via Merge by Distance. Solvable mazes need two start points.

## Environment scenes

Five scene setups, each with the values read from a full-size frame (the spoken values were rougher: "a few hundred", "close to one"). Node names are current in 5.2.

- **Dust motes in a sunbeam**: tiny drifting spheres inside a box that matches the light shaft. Steps: a box object `Beam` (Display As Wire or Bounds) roughly fitting the light path, inside the light's cone. A cube `Dust` with a new node-tree modifier. Object Info (Beam, Relative) > Mesh to Volume (Density 1.0, Resolution Mode Amount, Voxel Amount 64, Interior Band Width 0.2 m) > Distribute Points in Volume (Mode Random, Density 500, Seed 0) > Set Position > Instance on Points (Instance = Ico Sphere Radius 0.003 m, Subdivisions 1) > Set Material (`Dust`) > Group Output. Offset: Noise Texture 4D (fBM, Normalize, Scale 5, Detail 2, Roughness 0.5, Lacunarity 2, Distortion 0) Color > Vector Math Subtract with (0.5, 0.5, 0.5) in the second vector > Set Position Offset. W of the noise = Scene Time Seconds x Math Multiply 0.02 (change the multiplier for speed). Pitfalls: noise Color is 0 to 1, so subtract 0.5 or every mote drifts the same way. Use an Ico Sphere, not a UV Sphere. Density is per cubic metre, so a 0.9 x 0.9 x 4.7 m box at 500 gave about 1,000 motes. Motes are lit only where the light reaches, so keep the box inside the spot or sun beam. Rebuild (5.2.2 Cycles, 128 samples, denoiser off, a spot light over a dark floor, measured 2026-11-08): the setup gave a drifting, speckled column of sub-pixel white points (1 to 2 px at 1280 wide, 6 m from a 35 mm camera). Keep the denoiser off or it erases the motes. The video's frame also has a warm haze shaft and dim motes; the nodes make only the motes, so add the fog box from `environments.md` (Volume Scatter, Density 0.1, Anisotropy 0.9) for the shaft and keep the Dust material dim. In 5.2 `Resolution Mode` and `Mode` are menu sockets: set `inputs['Resolution Mode'].default_value = 'Amount'` and `inputs['Mode'].default_value = 'Random'`. Check: verified [frame 02:34: Voxel Amount 64, band 0.2, Density 500, radius 0.003 m, multiply 0.020, noise Scale 5, Detail 2, Roughness 0.5]; rebuilt in 5.2.2.
- **Reusable footpath carved by a curve**: a groove in terrain with a dirt material that follows a curve you can edit. Steps: curve object `Path`, a subdivided grid `Ground` with a new modifier. Group Input Geometry > Set Position (Offset) > Set Material (`Dirt`, Selection from Less Than) > Group Output. Object Info (Path, Relative) > Curve to Mesh (no profile) > Geometry Proximity (Target Element Edges) Distance > Map Range (Clamp on, From Min 0, From Max 1.5, To Min -0.464, To Max 0) > Combine XYZ Z > Offset. The same Distance > Compare (Less Than, A distance, B 1.0) > Set Material Selection. Edit the curve in Edit Mode and groove and dirt move together. To Min sets the depth (negative sinks), From Max sets the width. Target Element must be Edges: the Faces default does not work on an edge-only mesh. Check: verified [frame 04:07: Map Range From Max 1.500, To Min -0.464, To Max 0.000, Less Than B 1.000, Proximity Edges].
- **Forest on a hill, none on cliffs, painted mask**: Poisson-spaced mixed pines on slopes that are flat enough and where you painted. Steps: `Hill` with a new modifier. Group Input Geometry > Distribute Points on Faces (Poisson Disk, Distance Min 1.11 m, Density Max 10, Seed 0) > Instance on Points (Pick Instance on) > Join Geometry (with the Group Input geometry) > Group Output. Collection Info (collection `Pines`, Separate Children on, Reset Children on) > Instance on Points Instance. Slope: Normal > Separate XYZ Z > Map Range (From Min 0.8, From Max 0.9, To Min 0, To Max 1) > Math Multiply > Distribute Density Factor. Paint mask: Weight Paint in red, rename the vertex group `Forest`, Named Attribute `Forest` (Float) into the other Multiply input. Trunk origins must sit at the tree base. Raise Distance Min if trunks overlap. A different slope trick is "Snow on ledges by slope" in `environments.md`. Check: verified [frame 06:31: Poisson Disk, Distance Min 1.11 m, Density Max 10, Map Range 0.800, 0.900, 0, 1, Pick Instance on, vertex group Forest].
- **Random lit windows that switch on over time**: extruded windows on a tower block with an animated probability. Steps: one joined object `Block` with one face per window, a new modifier. Extrude Mesh (Faces, Offset Scale 0, Individual on, Selection = Normal > Separate XYZ Z > Compare Equal B 0, Epsilon 0.001, so only the side walls) > Scale Elements (Face, Selection = first extrude Top, Scale 0.65) > Extrude Mesh (Selection = first extrude Top, Offset Scale -0.15, Individual) > Set Material `Window Glass` (Selection = second extrude Top) > Set Material `Window Lit` (Selection = Boolean Math And of the second Top and a Random Value Boolean) > Group Output. Animate Random Value Probability: frame 1 value 0, press I; last frame about 0.5, press I. The frame shows 0.555 at the end. Pair the lit material with an Emission shader. Check: verified [frame 08:51: Scale 0.650, offsets 0.000 and -0.150, Equal B 0.000 and epsilon 0.001, probability 0.555, Seed 0].
- **Snow layer on everything that faces up**: one merged smooth snow mesh over a whole scene. Steps: a cube `Snow` with a new modifier. Collection Info (scene collection, Relative) > Realize Instances > Distribute Points on Faces (Random, Density 1500, Selection = Normal > Separate XYZ Z > Compare Greater Than B 0.7) > Points to Volume (Resolution Size, Voxel Size 0.04 m, Radius 0.12 m) > Volume to Mesh (Grid, Threshold 0.1, Adaptivity 0) > Set Material `Snow`. Keep the voxel size smaller than the radius or the snow turns blocky. Heavy: about 130k faces at these values, so use the viewport switch from "Viewport vs render density" above. Check: verified [frame 10:27: Density 1500, Greater Than B 0.700, Voxel Size 0.04 m, Radius 0.12 m, Threshold 0.100].

## Curves and generators

- **Curve basics**: Curve Primitives (Arc, Spiral, Star, Quadrilateral, Circle). Resample Curve Count or Length. Fill Curve outputs a mesh so curve nodes go first. Fillet Curve Poly Count 1 gives hard bevels. Gear: Star -> Fillet Curve (Poly 1) -> Fill Curve -> Extrude Mesh. Smooth a jagged curve with Set Spline Type Bezier -> Set Handle Type Auto. Displace a line with Set Position offset from Noise Color - 0.5 scaled, and multiply by Spline Parameter Factor so roots stay fixed.
- **Hanging cable**: Curve Line, Resample (10), Set Spline Type Bezier, Set Handle Type Free, two Set Handle Positions (Left and Right, same Vector 0,0,-1).
- **Curve to Mesh with taper, radius, tilt**: Curve Circle profile (Resolution 4 for square, Fill Caps). Set Curve Radius before Curve to Mesh, fed by Spline Parameter Factor or Length through a Float Curve. Twist with Set Curve Tilt = Factor x multiplier (a Rotation or radians value, Math To Radians 360). Resample first. Extrude Mesh + Scale Elements (top) gives ridges.
- **Trim Curve, many curves, branches**: Trim Curve needs a non-cyclic curve. Grid -> Distribute -> Instance on Points (Curve Line) -> Realize Instances -> Set Position. Branches: Curve to Points (Count) gives Tangent, Normal, Rotation. Capture Spline Parameter before Curve to Points. Random Value Boolean thins. Endpoint Selection chooses tips.
- **Point connector**: Points from Distribute, Curve Line Set Position with Sample Index (Position) by Index. Resample Count = Attribute Statistic max Index. Curve to Mesh 0.01, Trim Curve with Start from Scene Time and End = Start + 0.1, Modulo 1. Capture Attribute does not work here.
- **Draw curves on a surface**: Bezier curve, Edit Mode, T > Draw tool, Depth Surface (not Cursor). Curve > Geometry Depth and Fill Caps. A Remesh modifier turns drawn curves into a character. Spirals: Extra Objects add-on, Add Curve > Spiral > Archimedean (5 turns, radius 0, growth 0.02), see.
- **Straps from a Bezier curve**: Face snapping Median, Ctrl to snap to surface. V > Vector then Automatic. Curve to Mesh with Quadrilateral (0.02 x 0.005), Fill Caps. Ctrl+T tilts points. Convert to Mesh to apply.

## Generators by subject

- **Brick wall from one curve (3.2+)**: Ground plane, Draw tool Surface. Resample Curve (0.2) -> Curve to Mesh -> Extrude Mesh (Edges, offset Z 0.2) -> Duplicate Elements (Faces) with Set Position offset Duplicate Index x 0.2 for height. Merge by Distance. Mesh to Points (Faces) gives the half-offset stagger, Join with vertex points. Instance on Points with a brick (0.2 x 0.1 x 0.1, origin at bottom, Bevel). Store the curve tangent as a Named Attribute "tan" early, then Align Rotation to Vector. Delete start points (Endpoint Selection) for interlocking ends. Random holes: Random Value Boolean 0.05. Sticking bricks: Translate Instances Y random. Wall height from curve Radius stored as "rad". Mortar via Ambient Occlusion (not on OptiX).
- **Barbed wire (nodes)**: Mesh to Curve, Resample (0.05), Curve to Mesh with a Join of two Curve Circles at +/- radius. Set Curve Tilt = Spline Parameter Length x multiplier. Barb: Curve Spiral, Curve to Mesh, duplicate rotated Z 180. Pointy tips: Factor x2 -> Ping Pong 1 -> Map Range From Max 0.1. Place: Instance on Points with selection Index Modulo 4 NOT, Align Rotation to Vector (Tangent). Swap the input for a cube and wire follows edges.
- **Barbed wire (2.9x modifiers)**: Units millimetres, cube 2 mm, apply scale. Array (10), Mirror Z, Simple Deform Twist X 360, Array Fit Curve with a Curve modifier. Barb: Screw modifier around the wire axis, Array Object Offset. Keep origins identical.
- **Cable bundle**: Plane -> Merge at Center -> extrude. Mesh to Curve, Curve to Mesh (Circle 0.02, res 6). Mesh Line -> Mesh to Points -> Instance on Points with the cable. Realize, then Set Position with Noise. Capture Index (Instance domain) before Realize for per-cable offsets in noise W. Pinch ends with Factor -> x2 -> Ping Pong 1 -> Map Range. Hanging: location offset x same profile. Per-cable colour: Store Named Attribute "cable" from White Noise, shader Attribute (Geometry type) into Hue. Lower Subdivision while editing. In 5.x Duplicate Elements with Duplicate Index in noise W is shorter.
- **Piped frosting, cream, soft serve (3.2)**: Bezier curve, Curve to Mesh with Star profile (radius 0.01), Fillet Curve (Limit Radius on). Pinch: Set Curve Radius = Radius x Factor via Float Curve, after Resample (0.005). Twist: Set Curve Tilt = Curve Tilt + Factor x twist. Subdivision Surface 1 to 2 and Set Position Noise x Normal x small, with Spline Parameter captured while still a curve. Clip start 0.01 for close views.
- **Sprinkles on frosting**: Distribute (Poisson, 20000, 0.008), Join, Instance with Cube 0.01 x 0.04, Subdivision, Scale Elements 0.25, Rotate Instances Z random tau. Tops only: Separate XYZ of Normal Z as Selection. Sprinkle shader: Object Info Random -> Color Ramp Constant (5 colours). Frosting shader: yellow, subsurface radius 0.002, roughness 0.25, Noise bump 0.01.
- **Fuzz on any mesh (3.4+)**: Distribute, Join. Draw four hair curves in a collection (roots at origin). Instance on Points Pick Instance, index from an Integer. Capture Normal early, Align Rotation to Vector (Z). Group with density, scale, seed, collection, Ctrl+Shift+D x4. Curve to Mesh (Circle res 3, radius 0.01), radius = 1 - Factor. Rotate and Scale Instances random. Density via Is Viewport Switch. Built-in alternative in 4.x: Add > Curve > Fur (Interpolate Hair Curves, density 10000) plus Curl Hair Curves from the asset browser, colour via an Attribute node reading a copied UV map, bake procedural materials, see.
- **Fuzz material inheriting base UV colour**: Set Material last. Attribute node type Instancer named as the UV map. Mix (Vector) with the Attribute Alpha as factor between UV Map and the instancer vector into the image. For deforming characters, capture original position, unwrap, scatter, restore.
- **Recursive subdivision greeble**: Plane, Subdivide Mesh. Subgroup: Separate Geometry (Face) Random Value Boolean, Subdivide on one half, expose Probability and Seed (seed +1 out), chain 4+. Extrude Mesh (Individual) then Scale Elements 0.9, offset from Noise. Lattice: Mesh to Curve of the pre-delete mesh, Curve to Mesh with Quadrilateral 0.01. Remesh modifier first for square cells.
- **Cobweb generator**: Draw curves on walls (Depth Surface). Resample Count 2, Curve to Mesh (res 3, 0.005). Instance a Curve Line (0.5) on a second Resample (0.05), Capture Normal -> Align Rotation to Vector, selection Random Boolean AND NOT Endpoint. Snap ends: Realize, Set Position (Endpoint Selection) with Geometry Proximity (Points) of surface points. Hanging: Set Spline Type Bezier, Handle Vector, two Set Handle Positions with Z = -(captured Spline Length x random 0 to 0.2). Three branch layers enough.
- **Countdown timer text (3.1+)**: String to Curves -> Fill Curve -> Extrude Mesh. Scene Time Seconds -> Value to String, Truncate, Modulo 60, minutes = Truncate(Divide 60), Join Strings with ":". Leading zero via Compare Less Than 10 -> Switch (String). Countdown: Subtract from start, Absolute, clamp at 0. Check from frame 0.
- **Animated text and trails (overview)**: Text object, split mesh islands, Delete over time with Constant interpolation. Emitter: points from a volume that scale down, instances on them, parent to a bone. No exact values.
- **Scribble Gen presets (paid)**: Append the presets collection or add its folder as an asset library. Draw (Surface). Modifier: Target Collection enables Collision and Snap End Points, Hang, Duplicates, Noise, End Pinching. Emit presets: Mode 0 instances, 1 points, 2 volume, 3 meshed volume, Speed, Shrink, Trim, Delete Hit Particles, Noise. Instance on curve and scatter: Target Collection for normals, Resolution, Alignment Influence, Random Transform. Simple Curve and Volume Line presets for horns and blobs. Export needs Realize Instances then Convert to Mesh.
- **Splatter from a drawn curve**: Curve to Points -> Points to Volume (Size, one Value 0.1) -> Volume to Mesh -> Subdivision. Random delete, noise Set Position, snap back with Geometry Proximity, Duplicate Elements (Point, 100) with noise W = Index. Smaller voxels tear more.

## Grease Pencil (4.3+)

- **Drawing to a per-frame mesh**: Add Grease Pencil Blank, draw mode. Nodes: Grease Pencil to Curves (Layers as Instances off) -> Resample -> Points to Volume -> Volume to Mesh. Auto key, a new drawing per frame in the Dope Sheet (Grease Pencil mode), onion skin. Smooth with Set Position + Blur Attribute. Thin strokes: Radius + Math Add. Direct conversion to mesh is not available, use a plane with the GP object in Object Info then Convert to Mesh.
- **Filled shapes from strokes**: Grease Pencil to Curves -> For Each Element over splines, Circle with the same point count, Set Position to spline points, Distribute, Points to Volume, Volume to Mesh, smooth.
- **Guided hair**: Duplicate a scalp patch (Shift+D, P > Selection), draw a few strands on a GP empty. Object Info of the cap -> Distribute (500) -> Interpolate Curves (Guide = Grease Pencil to Curves). Curve to Mesh (Circle 3), radius 1 -> 0 by Factor. Noise offset x Factor so roots stay. Parent hair to the cap and the cap to the head.
