# Effects and FX

Fire, lightning, liquid, cloth and glitch builds. Blender 2.82 to 5.2. Quick physics recipes need Blender 4.2+.

Reading map
- 5.x names: renamed settings that hit every effect here
- Fire: shader plane, real-time GN fire, fire HDRI, shader pack
- Lightning: Tesla arcs, branching GN bolt, modifier bolt, pack
- Liquid: wiggling text, chrome blobs, droplets, splatter
- Cloth: modifier skirt, Cloth Dynamics node, pressure pop
- Quick physics recipes: cloth drapes, cheese, flag, pillow, shirt, web, rigid body, Quick Liquid, ripples, fur, grass, ocean
- Glitch: pixelate, VHS, ASCII, painterly filter

## 5.x names

- Eevee Bloom checkbox is gone in Eevee Next (4.2+). Use the Compositor Glare node or render-time glare for glow. Emission strength 5 to 10 still drives it.
- Material Settings > Blend Mode Alpha Blend and Shadow Mode None became Render Method (Dithered or Blended) and a Transparent Shadows option in 4.2+. Check the Material Settings panel. Cycles needs more Light Paths > Transparent bounces for stacked planes.
- Mix RGB is Mix (Color). Separate RGB is Separate Color. Musgrave is Noise Texture with a Type dropdown.
- Shader to RGB still works in Eevee only.
- Blackbody node still exists and drives fire colour.
- Principled BSDF 4.0: Subsurface and Transmission were reworked (Transmission Weight, Subsurface Weight and Scale). Re-check any value copied from 2.x or 3.x.

## Fire

- **Procedural fire shader on a plane (2.91, Eevee)**: Plane rotated X 90, apply. Delete Principled. Mix Shader of Transparent and Emission (Alpha Blend, Shadow None, see 5.x names). Gradient Texture (Spherical) -> Mix factor, Ctrl+T (Node Wrangler), delete Mapping, Texture Coordinate = Object. Distortion: Noise (3D or 4D, scale 3) -> Subtract 0.5 -> Multiply 1.5 -> Combine XYZ (Z only) -> Vector Add to the coordinate. Animate with a Value `#frame` / -15 into Combine XYZ Z. Group (Ctrl+G) with scale, strength, translate. Second layer for pointiness. Limit distortion near the base: Separate XYZ Z -> Add offset -> Clamp 0-1 -> Multiply into strength. Egg shape: Vector Curves, lower top point of Z. Colour: Color Ramp (B-Spline, red edge, pale yellow ~0.2 saturation centre) -> Emission strength ~5. Sparks: second Emission Mix, Voronoi Distance -> Map Range (From Max 0.1) -> Mix RGB, factor from a taller duplicate gradient, strength ~10, own animated Z, wobble by a single-user copy of the distortion group (Z to X, strength 0.5). Fake volume: Array Constant Offset Y 0.1, count 5, second Array count 2 Y -0.5. Real volume: Cube with Principled Volume, density = clamp(flame + ember) inverted, emission via Mix. Fakes break at shallow angles.
- **Real-time fire from planes (GN, instance attributes 3.4+)**: Bezier curve (Draw tool, Surface). Curve to Points (Length 0.01), Set Point Radius. Rise: Set Position Offset = Index x (0,0,1), normalised by Attribute Statistic max, plus Scene Time Seconds x speed, Modulo 1, x distance. Random order: Random Value Integer instead of Index. Noise: second Set Position with Noise Color - 0.5, masked by the modulo value. Store Named Attribute "age". Instances: three crossed planes (duplicate, rotate X 90 and Z 90), Instance on Points, Rotate Instances random Z, Scale Instances via noise Map Range. Shader: Emission + Transparent, radial falloff from Object coordinates Vector Length, Layer Weight Facing hides edge-on planes, Noise 4D with W = Object Info Random x1000, Vector Curve Z teardrop, Color Ramp. Attribute node (Instancer, "age") -> Map Range (flipped) -> Power (~10, up to 100) for brightness and fade. Smoke: Emission and (Diffuse + Translucent) mixes. Mesh version replaces curve nodes with Distribute Points on Faces.
- **Animated fire HDRI (World, Eevee, 2.82)**: Background, Ctrl+T, Separate XYZ Z -> Mix (black/white) gradient. Color Ramp (B-Spline) Multiply with Noise, a crunched ramp with Blackbody in the black slot. Animate with Value driver `frame` x 0.02 into Combine XYZ Z.
- **Fire shader pack usage**: Upright plane, rotation and scale applied, origin in the middle, Object coordinates. Time = hash frame driver. Controls: flame and ember brightness, scale, widths, speed (higher is slower), noise scale (low gives candle), colours 1 to 3, cell shading steps. File > Append > Material with Fake User.

## Lightning

- **Tesla-coil arcs (GN 3.1)**: Targets in a collection. Source: Distribute Points on Faces, Join, Instance on Points with a Curve Line (0.1), rotation from distribute. Targets: Collection Info (Relative, Reset Children) -> Realize Instances -> Geometry Proximity (Points). Realize lines, Set Position (Endpoint Selection start) = Proximity Position. Add noise to the lookup (Noise Color - 0.5 x strength, 4D W = Scene Time / 10). Floating starts: Set Position noise then a second proximity back to the source. Disconnect when far: Distance Greater Than 2 m, NOT, into endpoint selection. Keep normal direction with Sample Index normal into Align Rotation to Vector. Resample 0.01, offset by noise x Factor x Float Curve, Accumulate Field (Spline) added to W so arcs differ. Delete Geometry (Spline) by Random Boolean or Index >= N. Flicker with Noise Greater Than 0.45. Thicken: Curve to Mesh (Circle small), radius from Factor via Float Curve x Spline Length (min 0.05). Emission 25, slightly blue. Set Material before the final join.
- **Realistic branching bolt (GN)**: Bezier 2 m vertical, handles Vector. Curve to Mesh (Circle res 3, 0.01), Set Curve Radius from Spline Length via Map Range. Resample Length 0.01, Capture Factor before trimming, Set Position Noise Color x strength - 0.5, multiplied by Factor through Float Curve (0 at ends). Noise scale 1, detail 10. Trim Curve End is the strike slider. Instance a Curve Line on the trimmed curve, rotation Align Rotation to Vector (Tangent) then 90 on Y, random spin from White Noise (not Random Value) via Map Range Vector -7 to 7. Branch count: Less Than ~0.25, NOT Endpoint AND. Realize, Resample so branches distort. Branches grow with the parent via a second Capture after the trim and a second Trim. Group, stack layers. Flash and fade: expose End (max 2), output named attribute "Factor", per-layer Power, Switch with Compare Greater Than 1 on End. Shader: Attribute "Factor" -> Clamp -> Mix Shader Fac (Transparent + Emission), unclamped to emission strength. Key End 0 to 2 over 60 frames Linear at 30 fps. Capture before trim or ends drift.
- **Bolt with Skin modifier (2.9)**: Plane, Merge at Center, extrude Z 10 m, Loop Cut 7. Vertex Group "focus" on the tip. Three Displace (Cloud, X, Y, Z, Object coords driven by an Empty), Subdivision, Skin last, Subdivision. Tip: Ctrl+A radius, Proportional Sharp. Shader: Emission + Transparent, Vector Math Length on Object coordinates, Greater/Less Than 11, grouped "bolt length" keyed Linear. Bridging arcs: animate the Empty Y with `frame/5`.
- **Lightning Pack V1 (paid)**: Append collections (single strike, continuous with noise modifier, arc electricity), place with Face snapping, Snap Center, Align Rotation to Target, default length 10 m. Use Render > Simplify if slow.

## Liquid

- **Liquid wiggling 3D text (3.2+)**: Curve object, new tree, delete Group Input. String to Curves (Align X Center, rotate X 90, rounded font), Resample (0.01), Realize Instances, Points to Volume (Size, voxel 0.02, radius 0.04), Volume to Mesh. Smooth modifier (repeat 100+). Thickness: Set Position offset Curve Tangent -> Vector Rotate Z 90 x scale (before Realize). Wiggle: Set Position Noise 4D Color - 0.5, W = Scene Time / n. Thicker: Duplicate Elements (Spline), offset Duplicate Index x (0,0,-0.01) before noise. Set Shade Smooth, Material, Film > Transparent. Round fonts only. Smaller voxels are slower.
- **Chrome blobs from drawn curves**: Draw tool curve. Curve to Points (Length 0.025) -> Points to Volume (Size, same value) -> Volume to Mesh. Smooth by edge-vertex averaging or Blur Attribute. Blobby ends: capture Spline Parameter Factor, Map Range (0.05 to 0.1) with Float Curve. Per-point radius: Alt+S in Edit Mode. Metallic 1, roughness 0, Environment Texture from Poly Haven, Film > Transparent. Noise after Curve to Points.
- **Water droplets and condensation (3.1+)**: Separate plane with a new tree, delete Group Input, drag the target in (Object Info, Relative). Distribute Points on Faces -> Points to Volume (Radius ~0.02, Voxel Amount) -> Volume to Mesh (Amount, same value from one Integer ~128). Radius Random Value (0.01 to 0.02). Poisson Disk (density 5000, min distance 0.03) for spaced beads. Set Shade Smooth, Principled white, roughness 0, transmission 1. Scales with the object. To put droplets on the object itself use Join Geometry plus Geometry to Instance at the end or UVs break. Realize collection instances for different droplets per can.
- **Splatter texture generator (Eevee 2.93)**: Plane and camera orthographic scale 2, 1024 square, Mix Shader Transparent + Emission. Noise Less Than 0.5 with Object coords, streaks via X scale 3, Voronoi droplets, Separate XYZ Y -> flipped Map Range puts droplets at the bottom. Edge mask: Vector Length -> Map Range (0.5 to 0.9) mixed with noise. Per frame: White Noise (1D) with W `#frame`, x1000 into noise vectors, Combine HSV random hue (S and V 1). Export: Film > Transparent, PNG RGBA, Render Animation. In scenes use Object Info Random instead.
- **Pickle jar glass**: Solidify and Subdivision, tight loops at bottom and mouth. Liquid: apply jar modifiers, select inner faces to the fill level, Shift+D, P, fill the top, check Face Orientation, F3 Flip Normals.
- **Liquid inflate (cheese)**: See Volume Cube in `geometry-nodes.md`.

- **Big liquid sims faster than Mantaflow**: [codepawl/spume](https://github.com/codepawl/spume) is an open-source GPU FLIP solver on NVIDIA Warp with whitewater, marching-cubes meshing and a Blender add-on. Use it for pours, splashes and tanks when Mantaflow is too slow at the resolution you need. Needs an NVIDIA GPU.

## Cloth

- **Cloth modifier skirt (classic, 2.9x)**: Subdivided plane with inset hole. Cloth physics Quality Steps 8, Speed Multiplier 3, Vertex Mass 1, collision quality 8, self-collisions on distance 0.001 to 0.01, impulse clamping 5. Collision on body objects. Pin Group vertex group on the top ring, assigned to the hip bone. Ten frames of rest pose first so cloth settles. Bake before rendering.
- **Cloth Dynamics modifier and node (5.2, checked 2026-11-07: bundled node-group asset "Cloth Dynamics (Experimental)", with Collider and Custom Force)**: Subdivide a plane. Add Modifier > Simulation > Cloth Dynamics. Pin group is a vertex group named "group". Colliders: Add > Simulation > Collider on the object, put them in a collection and select it under Effectors. Bendiness and Stretchiness, Tearing toggle with threshold. Delete or turn off the cache if it stops reacting, bake before rendering. The Cloth Dynamics node takes fields and textures, expose the collection with an empty Group Input socket. Merge by Distance 0.01 first. No self-collision. Unpack via File > External Data > Unpack Resources if saves get slow. Verify names in the installed 5.2 UI.
- **Pressure force and tearing**: Custom Force node in Effectors. Vector = Normal x Scale (~300), minus Field Average of the same vector so the mesh does not drift. Key Pressure or Stretchiness to inflate. To pop, apply pressure 2 to 3 frames then zero. Gravity off while floating. Pop on a frame: Scene Time -> Compare Equal (Epsilon) -> Mix between pressures, gravity Compare Greater Than, pin Compare Less Than. Tearing threshold as a field: Voronoi 4D Distance to Edge scale 2 -> Map Range 1.2 to 5. Smooth only torn edges via Edge Neighbors face count = 1. Delete lone faces with Face Neighbors count 0.
- **Hair dynamics**: Hair particle system with Pin Goal Strength 0.1 for sag. See modeling entries for density painting.

## Quick physics recipes

Short cloth, fluid, hair and ocean setups. Panel names are the default Properties editor. Values are as seen on screen, and `unverified` marks a value no frame confirmed.

- **Cloth drape on a table, bed or burger**: Plane larger than the object, Edit mode, right click > Subdivide until fine (16x16 or finer, more for tablecloths). Object: Physics > Collision. Plane: Physics > Cloth. Collisions > Object Collisions Distance 0.015 m, Self Collisions on. Play, pause when it looks right, then modifier dropdown > Apply. Finish with Subdivision Surface (Viewport 1, Render 2) and Solidify. Values differ by source. Blanket: Quality Steps 10 (default 5), Shrinking Factor -0.200 (negative, read from the panel), Self Collision Quality 2, Distance 0.015 m, Friction 5. Tablecloth: Self Collisions Friction 5.0, Distance 0.015 m, timeline end 150. Another tablecloth clip: Quality Steps 5 to 6 or higher, self-collision distance very low `unverified (frames missing)`.
- **Melted cheese slice**: Plane scaled to a slice, subdivide several times. Solidify first in the stack (Simple, Thickness 0.03 m in one clip, 0.023 m in another, Offset -1). Physics > Cloth (defaults Quality Steps 5, Vertex Mass 0.3 kg). Burger or patty: Collision. Cache Simulation Start 1, End 100, Bake, play (settles by frame 50 to 70). Too few subdivisions leave the slice stiff.
- **Flag with pin group and wind**: subdivide the plane, assign the pole-side vertices to a vertex group. Physics > Cloth preset Cotton, Quality Steps 5, Shape > Pin Group = that group, Shrinking Factor 0. Shift+A > Force Field > Wind: Strength 1000, Noise Amount 0.5, Shape Plane. Bake frames 1 to 250.
- **Pillow with cloth pressure**: Collision on each sofa part. Thin cube, loop cuts, dense subdivision. Cloth: Quality Steps 5, Vertex Mass 0.02 kg (not the 0.3 default), tick Pressure first, Pressure 8.000. Bake, then Subdivision and Shade Smooth.
- **T-shirt on a hanger**: Cube, apply scale, three loop cuts each way. Alt+E > Extrude Faces Along Normals for sleeves, delete sleeve ends and the bottom, K knife a V neck. Hanger: a second cube merged at centre, Mirror (X, Merge 0.001 m), Skin, Collision. Shirt: Ctrl+2, then Cloth Quality Steps 10, Object Collisions 0.015 m, Self Collisions 0.001 m, Shrinking Factor 0.2 heard, -0.200 shown `unverified`. Raise steps if cloth passes through.
- **Spider web**: Circle 16 vertices, Fill Nothing, extrude and scale, loop cuts, inset, X > Only Faces. Pin ends in a vertex group, Subdivide with Fractal 0.122. Cloth Pin Group, Shrinking Factor 0.006 (small tightens, large tears), Self Collisions Distance 0.001 m (default 0.015 m). Bake.
- **Rigid body scatter (fries)**: box Rigid Body Passive, Shape Mesh (Source Deform), Margin 0.001 m. One fry Active, Mass 0.01 kg (default 1), Shape Capsule, Margin 0.001 m. Select all fries with the tested one active, F3 > Object > Rigid Body > Copy from Active, play.
- **Quick Liquid sauce or glaze**: small sphere, key Location (I) at the start and end of the path. F3 "effect" > Object > Quick Effects > Quick Liquid, scale the domain over the object. Domain Physics: Resolution Divisions 64 (32 default), Cache Type All, Frame End 180 (ketchup) or 500 (glaze). Sphere: Fluid Type Flow, Flow Behavior Inflow (the default Geometry must change). Target object: Fluid Effector, Effector Type Collision. Domain Bake All.
- **Water ripples with Dynamic Paint**: dense subdivided plane, Physics > Dynamic Paint > Type Canvas > Add Canvas, Surface Type Waves (Speed 1.00, Damping 0.04, End 250). Falling sphere: Dynamic Paint > Type Brush > Add Brush. Play.
- **Fur ball with hair dynamics**: UV Sphere, Shade Smooth, Particles > + > Hair. Hair Length 0.4 m, Segments 5, Advanced on, Hair Dynamics on, Quality Steps 10. Physics > Forces > Brownian 0.15 (makes it fuzzy). Children Interpolated, Display 21, Render 100. Bake. Stiffness 2.0 is `unverified`.
- **Grass tuft from a plane**: Plane with an Image Texture in Base Color, Particles > Hair, Advanced, Emission Number 3000, Hair Length 0.15 m, Segments 5, Brownian 0.12, Children Interpolated. Roughness Endpoint 0.1, Random 0.17 `unverified`.
- **Ocean modifier with foam**: Plane, Add Modifier > Ocean. Waves Scale 1.5, Choppiness 1.78, Alignment 0.395, Direction 6.5 deg, Damping 0.201 (only Scale and Choppiness were verified). Foam on, Data Layer "Foam", Coverage 0.3. Material: Base Color about #3B576C, Roughness about 0.33, Transmission Weight 1.0. Add Shader after the Principled, Emission to its second socket, Attribute node (Geometry, Name "Foam") through a Color Ramp into Emission Color. The name must match the Data Layer exactly. Animate Time: 1.00 at frame 1, 6.51 at frame 250. Finish with Resolution 12, Random Seed 16, Repeat X and Y 3.

## Glitch and screen effects

- **Pixelate node group and pixel-stretch glitch (2.92)**: Plane under a camera, Image Texture with Window coordinates (or UV). Separate XYZ -> Snap (increment 1 / pixels via Divide) on X and Y -> Combine XYZ. Square pixels: multiply X increment by height / width. Mix to switch UV and Window. Group it. Distort: noise vector through the pixelator, Map Range, Separate X (scale ~500) x Y snap. Mask: second Noise (scale ~2) -> Mix between pixelators. Interpolation Closest, Extension Extend. Animate Mapping Z `#frame`/100.
- **VHS glitch from a clip, shader only**: Plane, Image Texture as Movie (frames = clip length, Cyclic, Auto Refresh), Window coordinates. Distortion: Voronoi (Object, Smooth F1) with Mapping X 0 -> Combine XYZ Y into Mapping location, `#frame`/200. Dispersion: Separate Color three copies, shift R and B by +/- value on X. Roll: Mapping Y with Noise F-curve modifier and Limit. Static: Noise 4D W = frame, Map Range, Greater Than. Render with View > Viewport Render Animation.
- **ASCII art from image or video, shader only (2.92)**: Sprite sheet: Text Effects add-on, Read Lines, 32 x 32 white PNGs dark to light with a blank at the end. Orthographic camera, plane, Window coordinates (resolution = media), Interpolation Closest, Extension Extend. Pixelate with Snap. Tile: original minus pixelated -> Mapping scale = resolution. Sprite lookup: Mapping scale X = 1 / characters, location X = Snap(value) from the pixelated brightness (Separate HSV V -> Invert). Mix colour by sprite as factor. Above ~96 resolution use UV and zoom. In 4.x also possible via String to Curves picked by Index = brightness x count.
- **Painterly filter (Voronoi lookups)**: Camera fills a plane, Window coordinates, Closest and Extend. Three Voronoi (Position) lookups at scales N, 2N, 4N chained by Mix with one Noise's R, G, B as masks. Distort the vector by Noise - 0.5 x 0.2 divided by resolution. 4D noise W = hash frame animates. Focal mask: Empty Object coordinates -> Length -> Map Range.
