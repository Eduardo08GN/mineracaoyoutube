### 1.1 Receita sugerida
- **Malha:** `PlaneGeometry(W, H, 1024, 1092)`. No vertex shader, `y = texture(uDem, uv).r * escala * exagero`, com a normal por
  diferenças finitas do próprio DEM.
- **Projeção:** para não esticar a Patagônia, o vertex shader aplica `x *= cos(lat)` (sinusoidal, de área igual), centrado em
  −76°. As UVs continuam em lon/lat e as texturas da G4 não mudam.
- **Cor:** albedo Natural Earth × `hillshade_ao` (G4) × luz em tempo real suave, mais a rampa hipsométrica do monolith só como
  reforço de altitude.
- **Escalas:** **continente** (este) → **região** (recorte Copernicus GLO-90 na G4, malha própria) → **cidade** (GLB do
  three-map-terrain, §6), com corte ou dissolve entre as malhas. O raster de 4096 dá **~2,3 km por pixel**: serve para o
  continente, não para um close de cidade.

### 1.2 Métodos (YouTube, legendas lidas)
- `XYqDhADSKEk` (NACIS, Russ White, "Stylized terrain shading through layer blending"): sombra suave (*sky model*) em vez de
  hillshade duro, mais textura de hachura empilhada por intensidade.
- `1jLUQXzcfDI` ("Remastering Natural Earth", Tom Patterson e Nathaniel Kelso): por que a tinta cruzada com bioma lê melhor que a
  hipsometria pura.
- `G0hWjD0n46c` (colorir terreno por altura no three).
- `hHGshzIXFWY` (SimonDev, heightmap).

### 1.3 Leitura do PNG de 16 bits (testado em `D:/tmp/levant_mar/teste_install/t.mjs`)
```ts
import {decode} from 'fast-png';                      // 8.0.0, MIT
const p = decode(new Uint8Array(await (await fetch(staticFile('dados/nivel.png'))).arrayBuffer()));
// p.depth === 16, p.data é Uint16Array (conferido)
const h = new Uint16Array(p.data.length);
for (let i = 0; i < h.length; i++) h[i] = THREE.DataUtils.toHalfFloat(p.data[i] / 65535);
const tex = new THREE.DataTexture(h, p.width, p.height, THREE.RedFormat, THREE.HalfFloatType);
tex.minFilter = tex.magFilter = THREE.LinearFilter; tex.needsUpdate = true;   // HalfFloat é filtrável no WebGL2 sem extensão
```
- **Precisão:** meia precisão perto de 1,0 dá 2^-11, cerca de 3,4 m em 7.000 m. Basta para a costa.
- **`delayRender`:** carregar dentro dele, como as fontes do `Hud.tsx`.
- **`pais.png`:** usar **`NearestFilter`** (o id não pode ser interpolado) ou `texelFetch` com textura inteira.

vez**. É um "fato contraintuitivo" pronto para o roteiro (`whatif-es-adaptacao-e-take-inedito`) e mostra o mundo mudando no plano.
